# v0.4.0 - Richer Demo And Docs

Date: 2026-05-28

`v0.4.0` expands the public integration showcase and adds consumer-facing
documentation without changing the core event contract.

## Highlights

- Adds backend-provided demo scenario presets.
- Adds scenario execution controls to the demo UI.
- Adds event type counts, sanitized event payload details, and live state
  rendering to the demo inspector.
- Keeps `end` event content out of chat rendering and inspector content text.
- Adds a provider/prompt override example for consumer-owned integrations.
- Adds demo showcase and troubleshooting docs.

## Install

```bash
pip install "untamedai-runtime==0.4.0"
```

Demo extras:

```bash
pip install "untamedai-runtime[fastapi]==0.4.0"
```

## Compatibility

- Existing graph builders, provider protocols, store protocols, and FastAPI
  route factory APIs remain compatible.
- Existing SSE event ordering is unchanged.
- Core install still depends only on LangGraph.
