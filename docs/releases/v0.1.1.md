# v0.1.1 - Alpha PyPI Release

Date: 2026-05-28

`v0.1.1` is the first alpha release intended for PyPI publication. It keeps the
runtime behavior from `v0.1.0` and adds the release workflow and public README
clarifications that were added after the `v0.1.0` tag.

## Highlights

- Publishes from a source tag that includes the GitHub Actions Trusted
  Publishing workflow.
- Clarifies alpha API status and production authentication responsibility in
  the README.
- Uses matching source, tag, GitHub release artifacts, TestPyPI smoke, and PyPI
  artifact set.
- Keeps public runtime scope unchanged from `v0.1.0`.

## Install

PyPI:

```bash
pip install untamedai-runtime==0.1.1
```

Source:

```bash
git clone https://github.com/wkddns40/untamedai-runtime.git
cd untamedai-runtime
git checkout v0.1.1
pip install -e ".[fastapi,dev]"
```

## Verification

Validated locally:

```bash
python -m pytest
python -m ruff check .
python -m mypy src
python -m build
python -m twine check dist/*
```

TestPyPI and PyPI uploads are performed through GitHub Actions Trusted
Publishing with the `publish.yml` workflow.

## Limitations

- API surface is alpha and may change before `1.0.0`.
- Default providers are deterministic fakes intended for tests and demos.
- OpenAI and Supabase integrations require optional extras and user-owned
  credentials.
- FastAPI router does not include built-in authentication; consumers must pass
  an `auth_hook`.
- Demo UI is an integration showcase, not a production frontend.
