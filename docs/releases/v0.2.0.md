# v0.2.0 - FastAPI Route Factory Stabilization

Date: 2026-05-28

`v0.2.0` hardens the public FastAPI route factory while keeping the SSE event
contract compatible with `v0.1.x`.

## Highlights

- Adds `ChatRouterSettings` for history limits and SSE response headers.
- Adds `bucket_resolver` for application-owned metrics bucketing.
- Keeps `auth_hook`, `metric_hook`, and `config_factory` as stable extension
  points.
- Exports FastAPI callback types from `untamed_companion.fastapi`.
- Adds a FastAPI auth-hook example.
- Expands integration docs for auth, config, metrics, and non-FastAPI SSE
  transport usage.

## Install

PyPI:

```bash
pip install untamedai-runtime==0.2.0
```

FastAPI extra:

```bash
pip install "untamedai-runtime[fastapi]==0.2.0"
```

## Compatibility

- Existing `create_chat_router(...)` calls remain valid.
- Existing SSE event ordering is unchanged.
- FastAPI authentication remains application-owned through `auth_hook`.
- The default router remains unauthenticated for tests and demos.
