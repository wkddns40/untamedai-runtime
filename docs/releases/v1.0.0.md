# v1.0.0 - Stable Public API

Date: 2026-05-28

`v1.0.0` declares the public runtime API stable. The release keeps existing
`0.4.0` behavior compatible while moving future breaking changes to major
versions only.

## Highlights

- Declares the SSE event contract stable.
- Declares graph builders and `GraphRuntime` stable.
- Declares store/provider/prompt protocols stable.
- Declares the FastAPI route factory API stable.
- Adds API stability documentation.
- Adds an alpha-to-1.0 upgrade guide.
- Keeps optional extras and core dependency behavior compatible.
- Adds the missing `coffee-ko` demo scenario preset.

## Install

```bash
pip install "untamedai-runtime==1.0.0"
```

Optional extras:

```bash
pip install "untamedai-runtime[fastapi]==1.0.0"
pip install "untamedai-runtime[openai]==1.0.0"
pip install "untamedai-runtime[supabase]==1.0.0"
pip install "untamedai-runtime[postgres]==1.0.0"
```

## Compatibility

- Existing `0.4.0` graph, SSE, FastAPI, store, provider, and prompt usage
  remains compatible.
- Existing SSE event ordering is unchanged.
- Core install still depends only on LangGraph.
- Production authentication remains application-owned.
