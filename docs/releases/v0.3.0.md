# v0.3.0 - Optional Persistence Integrations

Date: 2026-05-28

`v0.3.0` hardens optional Supabase and Postgres integration surfaces while
keeping core installs dependency-light.

## Highlights

- Adds configurable Supabase table, column, and RPC names.
- Allows injecting a Supabase-like client for tests and custom clients.
- Adds `create_async_postgres_checkpointer(...)` for LangGraph async Postgres
  checkpointing.
- Adds `PostgresCheckpointSettings` for checkpointer setup and pipeline
  options.
- Adds persistence documentation with Supabase snippets and Postgres
  checkpointer usage.

## Install

Supabase:

```bash
pip install "untamedai-runtime[supabase]==0.3.0"
```

Postgres checkpointer:

```bash
pip install "untamedai-runtime[postgres]==0.3.0"
```

## Compatibility

- Core install still depends only on LangGraph.
- Existing `SupabaseCompanionStore(url=..., key=...)` calls remain valid.
- Existing SSE event ordering is unchanged.
- Production database schema remains application-owned.
