# v0.1.0 - Initial Public Runtime

Date: 2026-05-28

`v0.1.0` is the first public release of `untamedai-runtime`.

## Highlights

- Public LangGraph chat, greeting, and daily emotion graph builders.
- Stable SSE event adapter and golden event contract fixtures.
- Provider protocols for LLM, embeddings, weather, greeting, and emotion
  analysis.
- Companion store protocol with in-memory and optional Supabase adapters.
- Neutral prompt provider with app-owned override support.
- Optional FastAPI chat router factory.
- Demo showcase with English/Korean scenarios, static SSE inspector, reset
  endpoint, and daily emotion dry-run.
- GitHub Actions CI matrix for Python 3.11 and 3.12.
- Public release audit document and gitleaks configuration.

## Install

Source install:

```bash
git clone https://github.com/wkddns40/untamedai-runtime.git
cd untamedai-runtime
git checkout v0.1.0
pip install -e ".[fastapi,dev]"
```

Wheel install from GitHub release artifacts:

```bash
pip install untamedai_runtime-0.1.0-py3-none-any.whl
```

PyPI upload was not performed for this release step. A PyPI release can be cut
later after owner approval and package-name availability checks.

## Verification

Validated locally:

```bash
python -m pytest
python -m ruff check .
python -m mypy src
gitleaks dir . --no-banner --redact --verbose
python -m build
```

Fresh install smoke was run from the built wheel with the FastAPI extra.

## Limitations

- API surface is alpha and may change before `1.0.0`.
- Default providers are deterministic fakes intended for tests and demos.
- OpenAI and Supabase integrations require optional extras and user-owned
  credentials.
- FastAPI router does not include built-in authentication; consumers must pass
  an `auth_hook`.
- Demo UI is an integration showcase, not a production frontend.
- No PyPI upload is included in this release step.
